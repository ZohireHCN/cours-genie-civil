# Aide-mémoire AutoCAD

[← Retour au sommaire](README.md)

Tapez le raccourci puis Entrée. Entrée ou Espace répète la dernière commande ; Échap annule.

## Coordonnées

| Saisie | Exemple | Sens |
| --- | --- | --- |
| Absolue | `10,5` | Point (10 ; 5) |
| Relative | `@3,0` | 3 vers la droite depuis le dernier point |
| Polaire | `@4<60` | 4 unités à 60° (0° = Est, sens anti-horaire) |

## Touches de fonction

| Touche | Rôle |
| --- | --- |
| F3 | Accrochage aux objets (OSNAP) |
| F7 | Grille |
| F8 | ORTHO |
| F9 | Résolution |
| F10 | Repérage polaire |
| F11 | Repérage d'accrochage |
| F2 | Historique des commandes |

## Dessin

| Raccourci | Commande | Raccourci | Commande |
| --- | --- | --- | --- |
| L | LINE (ligne) | PL | PLINE (polyligne) |
| C | CIRCLE (cercle) | A | ARC |
| REC | RECTANG (rectangle) | POL | POLYGON |
| EL | ELLIPSE | PO | POINT |
| XL | XLINE (droite infinie) | SPL | SPLINE |

## Modification

| Raccourci | Commande | Raccourci | Commande |
| --- | --- | --- | --- |
| E | ERASE (effacer) | M | MOVE (déplacer) |
| CO | COPY (copier) | RO | ROTATE (rotation) |
| MI | MIRROR (symétrie) | SC | SCALE (échelle) |
| O | OFFSET (décaler) | TR | TRIM (ajuster) |
| EX | EXTEND (prolonger) | F | FILLET (raccord) |
| CHA | CHAMFER (chanfrein) | S | STRETCH (étirer) |
| AR | ARRAY (réseau) | X | EXPLODE (décomposer) |
| J | JOIN (joindre) | BR | BREAK (couper) |
| LEN | LENGTHEN (modifier la longueur) | MA | MATCHPROP (copier les propriétés) |

## Organisation

| Raccourci | Commande |
| --- | --- |
| LA | LAYER (calques) |
| B | BLOCK (créer un bloc) |
| I | INSERT (insérer un bloc) |
| W | WBLOCK (bloc vers fichier) |
| T / DT | MTEXT / TEXT |
| H | HATCH (hachures) |
| D | DIMSTYLE (style de cote) |
| DLI / DAL / DRA / DDI / DAN | Cotes linéaire / alignée / rayon / diamètre / angle |
| DCO | DIMCONTINUE (cotes en chaîne) |
| PR | PROPERTIES (propriétés) |
| DI | DIST (mesurer une distance) |
| AA | AREA (aire et périmètre) |
| PU | PURGE |
